# 🏗️ Core Module

Bu klasör, uygulama genelinde paylaşılan temel yapıları barındırır.

### İçerik:
- **`theme/`**: Uygulamanın genel tema ayarları, `AppTheme` ve `AppColors` gibi stil tanımları.
- **`constants/`**: Uygulama genelinde kullanılan sabit metinler, API anahtarları veya konfigürasyonlar.
- **`extensions/`**: Dart veya Flutter sınıflarına eklenen genişletme (extension) metodları.
