# 💾 Data Module

Bu klasör, uygulamanın veri katmanını (Data Layer) temsil eder.

### İçerik:
- **`models/`**: JSON verilerini Dart nesnelerine dönüştüren model sınıfları (Örn: `post_model.dart`).
- **`services/`**: Dış kaynaklarla (Cloud Firestore, Realtime Database, Auth vb.) iletişim kuran servis sınıfları.
